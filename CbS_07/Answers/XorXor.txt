1) Если сделать XOR для двух строк в кодировке ASCII "Привет, мир!" и "Привет, мир!", какой будет результат?
Ответ:
XOR = \x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00 т.е. строка из нулевых байтов
т.к. строки полностью совпадают, а XOR равен 1 если биты символов разные
-----------------------------------------------------------------------------
2) Приведи пример двух бинарных строк длиной 4 символа, которые при операции XOR друг с другом дадут одну из исходных.
Ответ:
Чтобы A XOR B = A || B, необходимо, чтобы A || B = 0000.
То есть, одна из строк должна быть строкой из нулей.
Явный пример:
A = 0101
B = 0000
A XOR B = 0101 → результат = A
-----------------------------------------------------------------------------
3) Реши данное выражение (напиши, что останется после выполнения всех операций XOR):
(A XOR B) XOR A
Ответ: 
Коммутативность и ассоциативность
(A XOR B) XOR A
(B XOR A) XOR A
B XOR (A XOR A)
B XOR 0 = B
